# WebBasics — Learn HTML, CSS, and JavaScript

A beginner-friendly site with structured lessons, live examples, and interactive practice.

## Structure

```
/learning-website
├── index.html         # Home
├── html.html          # HTML Topics
├── css.html           # CSS Topics
├── javascript.html    # JavaScript Topics
├── contact.html       # Contact / About (+ form validation)
├── /css
│   └── style.css      # Styles, light/dark themes, responsive
├── /js
│   └── main.js        # Interactivity (theme toggle, collapsibles, examples)
├── /images            # Assets
├── /examples          # Standalone examples (optional)
└── README.md
```

## Getting started

Open `index.html` in your browser. Navigate to topic pages via the header.

## Features

- Semantic HTML5 layout and navigation
- Responsive design with media queries
- Theme switcher (light/dark) with localStorage persistence
- Collapsible topic sections
- Toggle between example code and rendered output
- Basic nav highlighting and contact form validation
