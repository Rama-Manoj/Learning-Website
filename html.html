Semantic elements describe their meaning to the browser and developers. They create clear page regions like headers, navigation, main content, sidebars, and footers, which helps accessibility tools and search engines understand your layout.

  • <header>: Introductory content, logo, page title
  • <nav>: Primary navigation links
  • <main>: Unique main content of the document
  • <article>: Self-contained composition
  • <section>: Thematic grouping with a heading
  • <aside>: Tangentially related content (sidebar)
  • <footer>: Footer for a section or the page
  • <figure> and <figcaption>: Media with caption
<!-- Page header (site identity, nav trigger) -->
<header>Site header</header>

<!-- Main navigation landmark -->
<nav aria-label="Primary">Main navigation</nav>

<!-- Main content landmark (one per page) -->
<main>
  <!-- Standalone content block -->
  <article>
    <header><h2>Article title</h2></header>
    <section>
      <h3>Section heading</h3>
      <p>Section content</p>
    </section>
    <aside>Related info</aside>
    <figure>
      <img src="https://via.placeholder.com/300x120" alt="Placeholder graphic">
      <figcaption>An illustrative figure with a caption.</figcaption>
    </figure>
    <footer>Article footer</footer>
  </article>
</main>

<!-- Page footer -->
<footer>Site footer</footer>

HTML provides six levels of headings: h1 through h6. Use them to create a clear document outline and hierarchy. Always use headings in order (h1 → h2 → h3, etc.) for accessibility.

Heading Hierarchy:

  • h1: Main page title (use only one per page)
  • h2: Major sections
  • h3: Subsections
  • h4-h6: Further subdivisions

Best Practices:

  • Use headings in logical order
  • Don't skip heading levels
  • Use headings for structure, not styling
  • One h1 per page for SEO

HTML provides various elements for formatting and emphasizing text. Use semantic elements for meaning, not just appearance.

Semantic Elements:

  • <strong>: Important text (bold)
  • <em>: Emphasized text (italic)
  • <mark>: Highlighted text
  • <small>: Small print
  • <del>: Deleted text
  • <ins>: Inserted text

Presentational Elements:

  • <b>: Bold (no semantic meaning)
  • <i>: Italic (no semantic meaning)
  • <u>: Underline
  • <s>: Strikethrough
  • <sub>: Subscript
  • <sup>: Superscript
<!-- Semantic formatting -->
<p>This is <strong>important</strong> text.</p>
<p>This is <em>emphasized</em> text.</p>
<p>This is <mark>highlighted</mark> text.</p>
<p><small>This is small print.</small></p>
<p>Price: <del>$100</del> <ins>$80</ins></p>

<!-- Presentational formatting -->
<p>This is <b>bold</b> text.</p>
<p>This is <i>italic</i> text.</p>
<p>This is <u>underlined</u> text.</p>
<p>This is <s>strikethrough</s> text.</p>
<p>H<sub>2</sub>O (water)</p>
<p>E = mc<sup>2</sup> (Einstein's equation)</p>

<!-- Blockquotes -->
<blockquote>
  <p>"The best way to learn is by doing."</p>

HTML provides three types of lists: unordered lists (<ul>) for collections, ordered lists (<ol>) for sequences, and definition lists (<dl>) for term-definition pairs.

List Types:

  • Unordered Lists (<ul>): Bullet points for collections
  • Ordered Lists (<ol>): Numbered sequences
  • Definition Lists (<dl>): Term-definition pairs
  • Nested Lists: Lists inside other lists

Attributes:

  • type: Bullet style (ul) or numbering style (ol)
  • start: Starting number for ordered lists
  • reversed: Reverse numbering order
<!-- Unordered List (bullets) -->
<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Cherries</li>
</ul>

<!-- Ordered List (numbers) -->
<ol>
  <li>First step</li>
  <li>Second step</li>
  <li>Third step</li>
</ol>

<!-- Ordered List with custom start -->
<ol start="5">
  <li>Fifth item</li>
  <li>Sixth item</li>
</ol>

<!-- Definition List -->
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

Tables organize data into rows and columns. Use <thead>, <tbody>, and <tfoot> for structure, and attributes like colspan and rowspan to merge cells.

<table>
  <caption>Quarterly Sales (USD)</caption>
  <thead>
    <tr>
      <th>Region</th>
      <th colspan="2">Q1</th>
      <th>Q2</th>
    </tr>
    <tr>
      <th></th>
      <th>Online</th>
      <th>Retail</th>
      <th>All</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">North</th>
      <td>12,000</td>
      <td>9,500</td>
      <td rowspan="2">21,500</td>
    </tr>
    <tr>
      <th scope="row">South</th>
      <td>8,000</td>
      <td>13,500</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td colspan="3">45,000</td>
    </tr>
  </tfoot>
</table>

Forms collect user input. Always pair inputs with <label> using the for and matching id. Use appropriate type and validation attributes such as required, minlength, and pattern.

<form>
  <!-- Text inputs with labels and placeholders -->
  <label for="fullname">Full name</label>
  <input id="fullname" name="fullname" type="text" placeholder="Ada Lovelace" required>

  <label for="email">Email</label>
  <input id="email" name="email" type="email" placeholder="you@example.com" required>

  <!-- Radios (choose one) -->
  <fieldset>
    <legend>Subscription plan</legend>
    <label><input type="radio" name="plan" value="basic" checked> Basic</label>
    <label><input type="radio" name="plan" value="pro"> Pro</label>
  </fieldset>

  <!-- Checkboxes (choose many) -->
  <fieldset>
    <legend>Interests</legend>
    <label><input type="checkbox" name="int" value="html"> HTML</label>
    <label><input type="checkbox" name="int" value="css"> CSS</label>
    <label><input type="checkbox" name="int" value="js"> JavaScript</label>
  </fieldset>

  <!-- Select menu -->
  <label for="country">Country</label>
  <select id="country" name="country" required>
    <option value="" disabled selected>Choose...</option>
    <option>USA</option>
    <option>India</option>
  </select>

  <!-- Pattern and length validation -->
  <label for="zip">ZIP code</label>
  <input id="zip" name="zip" type="text" inputmode="numeric" pattern="\\d{5}" placeholder="12345" required>

  <!-- Multiline -->
  <label for="msg">Message</label>
  <textarea id="msg" name="msg" rows="3" minlength="10" placeholder="Tell us more..."></textarea>

  <button type="submit">Send</button>
</form>

Links connect pages and resources, while images enhance visual content. Always provide meaningful alt text for accessibility.

Link Types:

  • External: Links to other websites
  • Internal: Links within your site
  • Email: mailto: links
  • Phone: tel: links
  • Download: Links to files

Image Best Practices:

  • Always include alt attribute
  • Use descriptive alt text
  • Optimize file sizes
  • Use appropriate formats (WebP, JPEG, PNG)
<!-- External link -->
<a href="https://developer.mozilla.org/" target="_blank" rel="noreferrer">Visit MDN</a>

<!-- Internal link -->
<a href="/about.html">About Us</a>

<!-- Email link -->
<a href="mailto:contact@example.com">Contact Us</a>

<!-- Phone link -->
<a href="tel:+1234567890">Call Us</a>

<!-- Download link -->
<a href="document.pdf" download>Download PDF</a>

<!-- Image with alt text -->
<img src="https://via.placeholder.com/300x200" alt="Beautiful sunset over mountains" width="300" height="200">

<!-- Responsive image -->
<img src="https://via.placeholder.com/600x400" alt="Responsive image" style="max-width: 100%; height: auto;">

<!-- Image with caption -->
<figure>
  <img src="https://via.placeholder.com/400x300" alt="Team photo">
  <figcaption>Our development team</figcaption>
</figure>

The <head> contains metadata about the document: character set, viewport for responsive design, the title, and links to styles or scripts. Proper metadata ensures correct rendering and SEO.

<head>
  <meta charset="utf-8"> <!-- Unicode characters -->
  <meta name="viewport" content="width=device-width, initial-scale=1"> <!-- Mobile scaling -->
  <meta name="description" content="Beginner HTML metadata example"> <!-- SEO description -->
  <title>My Page</title>
  <link rel="stylesheet" href="styles.css">
  <link rel="icon" href="/favicon.ico">
</head>
Metadata is not directly visible; view page source to see <head> tags.

Every HTML document follows a specific structure. Understanding this foundation is crucial for creating well-formed web pages.

Document Structure Components:

  • <!DOCTYPE html>: Declares HTML5 document type
  • <html>: Root element containing all content
  • <head>: Metadata not displayed on page
  • <body>: Visible page content

Essential Head Elements:

  • <meta charset="utf-8">: Character encoding
  • <meta name="viewport">: Mobile responsiveness
  • <title>: Browser tab title
  • <link>: External resources (CSS)
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My Web Page</title>
    <link rel="stylesheet" href="styles.css">
  </head>
  <body>
    <header>
      <h1>Welcome to My Site</h1>
    </header>
    <main>
      <p>This is the main content of my page.</p>
    </main>
    <footer>
      <p>© 2024 My Website</p>
    </footer>
  </body>
</html>

HTML provides elements for embedding various types of media: images, audio, video, and external content via iframes.

Media Elements:

  • <img>: Images with alt text for accessibility
  • <audio>: Audio files with controls
  • <video>: Video files with controls
  • <iframe>: Embed external content
  • <canvas>: Draw graphics with JavaScript

Important Attributes:

  • alt: Alternative text for images
  • controls: Show media controls
  • autoplay: Start playing automatically
  • loop: Repeat media
  • src: Media source URL
<!-- Images -->
<img src="https://via.placeholder.com/300x200" alt="Sample image" width="300" height="200">

<!-- Responsive image -->
<img src="https://via.placeholder.com/600x400" alt="Responsive image" style="max-width: 100%; height: auto;">

<!-- Audio -->
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
  Your browser does not support the audio element.
</audio>

<!-- Video -->
<video controls width="400">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  Your browser does not support the video element.
</video>

<!-- YouTube Embed -->
<iframe width="560" height="315" src="https://www.youtube.com/embed/dQw4w9WgXcQ" 
        title="YouTube video player" frameborder="0" 
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
        allowfullscreen></iframe>

<!-- Canvas -->
<canvas id="myCanvas" width="200" height="100" style="border:1px solid #000;"></canvas>

HTML5 introduced many new semantic elements that provide better structure and meaning to web pages.

New HTML5 Elements:

  • <article>: Self-contained content
  • <section>: Thematic grouping
  • <aside>: Sidebar content
  • <nav>: Navigation links
  • <header>: Page/section header
  • <footer>: Page/section footer
  • <main>: Main content area
  • <time>: Date/time information
  • <progress>: Progress indicator
  • <meter>: Scalar measurement
<!-- HTML5 semantic structure -->
<header>
  <h1>Website Title</h1>
  <nav>
    <ul>
      <li><a href="#">Home</a></li>
      <li><a href="#">About</a></li>
    </ul>
  </nav>
</header>

<main>
  <article>
    <header>
      <h2>Article Title</h2>
      <p>Published on <time datetime="2024-01-15">January 15, 2024</time></p>
    </header>
    
    <section>
      <h3>Introduction</h3>
      <p>This is the introduction section.</p>
    </section>
    
    <section>
      <h3>Progress</h3>
      <p>Learning progress: <progress value="75" max="100">75%</progress></p>
      <p>Storage used: <meter value="6" min="0" max="10">6GB</meter></p>
    </section>
  </article>
  
  <aside>
    <h3>Related Links</h3>
    <ul>
      <li><a href="#">Related Article 1</a></li>
      <li><a href="#">Related Article 2</a></li>
    </ul>
  </aside>
</main>

<footer>

Accessibility (a11y) ensures content is usable by everyone. Provide text alternatives, keyboard navigation, and ARIA attributes where necessary. Prefer semantic elements over ARIA when possible.

Accessibility Principles:

  • Alt text: Describe images for screen readers
  • Semantic HTML: Use proper elements
  • Keyboard navigation: Ensure tab order
  • ARIA labels: Provide context
  • Color contrast: Ensure readability
<!-- Breadcrumb navigation -->
<nav aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Home</a></li>
    <li aria-current="page">Docs</li>
  </ol>
</nav>

<!-- Accessible image -->
<img src="team.jpg" alt="Our team standing in front of the office">

<!-- Accessible button -->
<button aria-pressed="false" aria-label="Toggle favorite">☆</button>

<!-- Form with labels -->
<label for="username">Username:</label>
<input id="username" type="text" aria-describedby="username-help">
<div id="username-help">Enter your username</div>
